# Authentication & RBAC

## Default registration
Every new public account is created as a Customer.

## Scoped roles
A staff role can be scoped to:
- Platform
- Vendor
- Individual property

## Initial roles
Super Admin, Admin, Vendor, Hotel Manager, Reception, Housekeeping, Customer.

## Security
Authorization must be enforced server-side with policies/gates. UI visibility alone is never permission control.
